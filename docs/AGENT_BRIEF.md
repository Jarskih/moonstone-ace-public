`py tools/worktree_setup.py --path D:/Amiga/wt/<task>` from HEAD, work and test there, report the changed file list. Your

## Patches
New area = new files: `asm/patches/<bin>.<area>.json` with its own `"funcs": [{"name", "impl"}]`. Lines are 1-based in the
moonshard asm, `orig` exact, `new` no more bytes than `orig`, no overlap with any existing range (add a test that checks it).
Retire executed-never DC blocks with `as_data` patches. Verify: `py tools/resource.py --verify --no-write`.

## Code
Idiomatic C++ (`-fno-exceptions -fno-rtti`, no STL, no new/delete, no global constructors). Pure logic in `src/engine` or
`src/game` (host-testable), hardware/asm glue in `src/rt` (no asm is linked since ROADMAP 7.1r: a `prg_`/`mog_` name in C++, or a name of `tools/cell_names.yaml` (`mogCurKnight`, ROADMAP 7.1s: add names there, `py tools/rename_cells.py --apply`), is a C++-owned cell,
generated by `tools/gen_data.py` from `extern_data` / `extern_cells`; a code-hunk cell you need is added to `asm/patches/<bin>.data_cells.json`, docs/PATCHES.md).
Shims keep the original register contract; document it in the file. Reproduce original quirks and comment them;
list deliberate differences in your report.

## Tests
Host tests with `clang++` (no STL): compare against a Python model of the asm and/or the lifted 68k oracle
(`tools/lift.py`, run it, never edit it); shims vs original in unicorn (pattern: `tests/test_sfx.py`, `tests/test_input.py`).
Prove sensitivity with one deliberate mutation. Compile-check new m68k code with `m68k-amiga-elf-g++`.

## Boot tests (headless)
`MS_AUTOPLAY` builds replay `autoplay.txt` without focus: `uaeshot.ps1 -Instance <n> -Autoplay <script>` with an instance
number other than the integrator's (`docs/AUTOPLAY.md`); compare shots with `tools/shotcmp.py`. Never kill other WinUAE
instances. A visible (not minimised) WinUAE window is fine; never steal focus or send real keystrokes.

## Report
Concise: what was ported (label -> function), what stays asm and why, files, patch-local funcs, CMake/abs diffs, register
contracts, test results, boot checks done or needed.
